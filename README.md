# 🏥 Clinic Booking System

A responsive clinic booking website designed to provide users with a simple and user-friendly way to explore the clinic, meet the medical team, and book appointments.

## 📌 About The Project

**Clinic Booking System** is a front-end academic group project focused on creating a modern and responsive clinic website.

The website includes three main pages:

* 🏠 Home
* 👩‍⚕️ Team
* 📅 Booking

The project also includes interactive JavaScript functionality, animations, and software testing.

## ✨ Features

* Responsive clinic website
* Modern and clean UI/UX
* Home page
* Medical Team page
* Appointment Booking page
* Interactive booking form
* Live appointment calendar
* JavaScript interactions
* Website animations
* Form validation
* Responsive design

## 📄 Main Pages

### 🏠 Home Page

The Home page introduces the clinic and provides users with an overview of the clinic's services.

### 👩‍⚕️ Team Page

The Team page introduces the clinic's doctors and medical team members.

### 📅 Booking Page

The Booking page allows users to select their preferred doctor, date, and available appointment time.

## 🗓️ Live Calendar

The Booking page includes an interactive calendar for selecting appointment dates and available time slots.

Users can select an available date and time to make an appointment.

## 🧪 Testing

Testing is an important part of the project.

Test cases are used to check:

* Navigation
* Doctor selection
* Date selection
* Time-slot selection
* Booking form validation
* Appointment booking
* User interface functionality
* Responsive design

A dedicated testing page is included in the project to document the test cases.
